face_recognition.load_image_file(file_path)
Loads an image file (.jpg, .png, etc.) into a numpy array so the library can process its pixels.

face_recognition.face_locations(img, number_of_times_to_upsample=1, model='hog')
Locates human faces in an image. Returns a list of tuples containing the pixel boundaries (top, right, bottom, left) for every face. The model parameter can be switched from 'hog' (fast, CPU) to 'cnn' (highly accurate, deep learning).

face_recognition.face_encodings(img, known_face_locations=None, num_jitters=1, model='small')
Generates the 128-dimensional mathematical vector (the face print) for faces in an image. Increasing num_jitters resamples the face multiple times for higher accuracy. The model parameter can be 'small' (5 landmarks, faster) or 'large' (default, 68 landmarks, more precise).

face_recognition.compare_faces(known_face_encodings, face_encoding_to_check, tolerance=0.6)
Compares an unknown face vector against a list of known face vectors. Returns a list of True or False values based on whether the match falls within the tolerance threshold.

face_recognition.face_distance(face_encodings, face_to_compare)
Calculates the exact numerical Euclidean distance between an unknown face vector and a list of known face vectors. Lower numbers mean the faces are a closer match.

face_recognition.face_landmarks(face_image, face_locations=None, model='large')
Maps out specific facial structures. Returns a dictionary containing lists of (x, y) coordinates pinpointing the chin, left eyebrow, right eyebrow, nose bridge, nose tip, left eye, right eye, top lip, and bottom lip.

face_recognition.batch_face_locations(images, number_of_times_to_upsample=1, batch_size=128)
An optimized function that finds face locations across a full batch of multiple images simultaneously. This is designed for rapid processing when using a GPU.
